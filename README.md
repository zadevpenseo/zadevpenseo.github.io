## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/zadevpenseo/zadevpenseo.github.io.git
cd zadevpenseo.github.io

# Install dependencies (respecting .nosync patterns)
npm install

# Start local development server
npm run dev

# Build for production with Pagefind search and XML sitemap
npm run build
```
