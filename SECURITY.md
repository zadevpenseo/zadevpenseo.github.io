# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of our systems architecture, client deliverables, and open-source assets with the utmost seriousness.

If you discover a security vulnerability, credential exposure, or unintended information disclosure in this repository or on [https://zadevpenseo.github.io/](https://zadevpenseo.github.io/):

1. **Do not open a public GitHub issue.** Public issues disclose vulnerabilities before patches can be deployed.
2. Please send a detailed report directly to **`devapenseo@gmail.com`**.
3. Include:
   - Type of vulnerability (e.g. secret leakage, XSS in interactive demos, dependency CVE).
   - Step-by-step reproduction steps or proof-of-concept.
   - Potential impact and suggested remediation.

## Response SLA

- **Acknowledgment:** Within 24 hours.
- **Triage & Remediation:** Within 48 hours for critical severity, within 7 business days for moderate severity.
- **Credit & Disclosure:** We will acknowledge your coordinated disclosure in the security release notes upon patch deployment.
