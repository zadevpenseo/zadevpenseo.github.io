## 1. Problem Space: PDF Tabular Chaos

Mengekstrak data transaksi keuangan dari berkas PDF ke spreadsheet Excel sering kali menjadi mimpi buruk:
- Baris transaksi bertingkat (*multi-line descriptions*) sering terpecah menjadi baris terpisah atau kolom yang bergeser.
- Format tanggal dan angka desimal/ribuan bercampur antara standar Indonesia (`1.000,00`) dan standar internasional (`1,000.00`).
- Penggunaan alat konverter otomatis online sering membocorkan data rahasia perbankan nasabah.


## 3. Aturan Validasi Saldo Otomatis (The Balance Invariant)

Setiap ekstraksi rekening koran diaudit melalui pengujian matematis tertutup:

```python
def verify_statement_balance(opening_bal: float, debits: list, credits: list, closing_bal: float) -> bool:
    calculated_closing = opening_bal + sum(credits) - sum(debits)
    # Toleransi selisih pembulatan mata uang < 0.01
    return abs(calculated_closing - closing_bal) < 0.01
```

Jika terjadi selisih bahkan sebesar Rp1,- skrip akan menandai baris spesifik untuk inspeksi manusia (*Human-in-the-Loop*).
