## 1. Problem Space: The Aggregation Incoherence Trap

In enterprise budgeting, retail supply chains, and macroeconomic planning, time series observations cluster into multi-tiered organizational trees:
* **Level 0 (National Aggregate):** Total corporate demand, nationwide electrical grid load, or macroeconomic GDP indicators.
* **Level 1 (Regional Aggregates):** Geographic zones (e.g., North, South) or primary business divisions.
* **Level 2 (Disaggregated Nodes):** Individual retail stores, SKU inventories, or operational branch units.

### The Incoherence Failure Mode

The standard operational flaw among quantitative analysts is estimating each node independently. Because individual state-space models optimize parameters in isolation, independent base forecasts produce **Aggregation Incoherence**:

```text
Forecast(Total) != Sum[ Forecast(Regional) ] != Sum[ Forecast(Branch) ]
```

When regional branch managers aggregate their localized forecasts, the sum diverges from headquarters top-down projections. In our empirical testbed, unconstrained base forecasts produced an average monthly divergence of **0.664 units (p &lt; 0.001)**, violating the basic accounting law of hierarchical consistency.

## 5. Mathematical Formulations

### A. Seasonal ARIMAX with Strictly Exogenous Regressors

```text
Phi_P(B^s) * phi_p(B) * (1 - B)^d * (1 - B^s)^D * (y_t - X_t * beta) = Theta_Q(B^s) * theta_q(B) * eps_t
```

Where:
* `B` is the backshift operator (`B^k * y_t = y_{t-k}`).
* `s = 12` represents the annual seasonal cycle.
* `X_t` denotes the matrix of strictly exogenous marketing and macroeconomic indicators.
* `eps_t` represents white-noise Gaussian innovations (`WN(0, sigma^2)`).

### B. Structural Summing Matrix S

The hierarchy tree is represented by matrix `S`:

```text
y_t = S * y_{K,t}

S = [ [1, 1, 1, 1],   <- Total
      [1, 1, 0, 0],   <- North
      [0, 0, 1, 1],   <- South
      [1, 0, 0, 0],   <- Branch 1
      [0, 1, 0, 0],   <- Branch 2
      [0, 0, 1, 0],   <- Branch 3
      [0, 0, 0, 1] ]  <- Branch 4
```

### C. MinTrace Optimal Projection Operator

```text
y_tilde_t = S * P * y_hat_t = S * (S^T * W^-1 * S)^-1 * S^T * W^-1 * y_hat_t
```

Where `W_shrink` is the regularized shrinkage covariance matrix of in-sample residuals:

```text
W_shrink = (1 - lambda) * Sigma_sample + lambda * diag(Sigma_sample)
```

## 7. The 4 Cognitive Callouts (Visual Taste & Editorial Nuance)

### Jendela Realitas (The Empirical Reality)
Ketika analis data menyajikan hasil ramalan kepada direksi atau dewan penguji tanpa rekonsiliasi, pertanyaan pertama yang selalu mematikan adalah: *"Mengapa jumlah target penjualan 4 cabang di slide 12 tidak sama dengan total target nasional di slide 3?"*. Selisih 0.6% sekalipun akan menghancurkan kepercayaan pemangku kepentingan terhadap seluruh metodologi yang dibangun.

### Jebakan Nalar (The Cognitive Trap)
Banyak praktisi mengira pendekatan *Bottom-Up* (meramal cabang lalu menjumlahkannya ke atas) sudah cukup menyelesaikan masalah inkoherensi. Ini adalah jebakan nalar: *Bottom-Up* mengabaikan sinyal makro pada level puncak dan mengakumulasi noise acak dari cabang-cabang kecil, sehingga varians galat pada level total membengkak.

### Kaidah Kedaulatan (The Governing Principle)
Rekonsiliasi optimal MinTrace memperlakukan ramalan dasar dari seluruh level sebagai estimator awal yang belum terkalibrasi. Melalui matriks pembobotan kovarian galat (`W`), MinTrace memproyeksikan ramalan ke ruang linear yang secara matematis menjamin bahwa cabang dan pusat selalu bertemu pada titik kesepakatan optimal.

### Kanvas Aksi (The Operational Canvas)
Gunakan pipeline Python deterministik kami yang memadukan `statsmodels` dengan aljabar linear NumPy/SciPy. Eksekusi skrip membutuhkan waktu kurang dari 10 detik, menghasilkan visualisasi 300 DPI siap cetak, serta mengekspor metrik evaluasi ke dalam format JSON dan Jupyter Notebook interaktif.
