### [1. Web Dev Design](/case-studies/web-dev-design/)
Fokus pada rekayasa frontend modern, performa Core Web Vitals sub-detik (LCP < 1.0s, CLS 0), serta arsitektur serverless edge dengan biaya hosting $0 USD/bulan.

- **[Gworky Edge Next.js Flagship](/case-studies/web-dev-design/gworky-edge-web-app/):** Next.js 15 pada Cloudflare Edge, PostgreSQL konkurensi tinggi, dan CI/CD otomatis.
- **[WooCommerce Store Rescue (#659829)](/case-studies/web-dev-design/woocommerce-enhancement-659829/):** Audit performa checkout non-destruktif, resolusi query `wp_usermeta`, dan isolasi staging.
- **[Modular Custom Web App Architecture (#659861)](/case-studies/web-dev-design/fullstack-custom-web-apps-659861/):** Skema data relasional bersih, autentikasi JWT stateless, dan endpoint REST idempoten.
- **[Elementor JSON UI Architecture Engine](/case-studies/web-dev-design/elementor-json-ui-engine/):** Ekspor-impor komponen UI bersih tanpa ketergantungan plugin pihak ketiga yang membebani DOM.

### [2. SEO](/case-studies/seo/)
Penerapan sistem pencarian organik menyeluruh yang menggabungkan Technical SEO, arsitektur data terstruktur Schema.org, Programmatic SEO berskala puluhan ribu halaman, serta Generative Engine Optimization (GEO/AEO) untuk bot kecerdasan buatan.

- **[Programmatic SEO Edge Scale Engine](/case-studies/seo/programmatic-seo-scale-engine/):** R2 payloads untuk 50+ hub kota dan universitas (arsitektur `zadit-pages` di Cloudflare Edge).
- **[Technical SEO & GA4/GSC Performance Audit](/case-studies/seo/technical-seo-vidio-tirto-audit/):** Bedah teknis performa organik dan jejak analitik pada platform media (Vidio.com & Tirto.id).
- **[National SEO Competition Award (WOM Finance)](/case-studies/seo/national-seo-competition-wom-finance/):** Dokumentasi artikel peringkat tinggi dan peraih Juara 3 Nasional kompetisi blogging SEO.
- **[Entity Knowledge Graph Architecture](/case-studies/seo/knowledge-graph-entity-architecture/):** Integrasi tri-node Wikidata (Q141474900, Q141474927), ORCID, dan Google Scholar.

### [3. Writer](/case-studies/writer/)
Penyusunan dokumen bisnis bernilai tinggi, naskah riset ilmiah bereputasi internasional, serta copywriting editorial mewah tanpa klise generik (*anti-AI slop*).

- **[Executive Pitch Decks & Partnership Collateral](/case-studies/writer/executive-pitch-decks-jcg-partnership/):** Format 16:9 master PowerPoint asli untuk The Jakarta Consulting Group dan kemitraan korporat.
- **[Business Feasibility & Financial Models](/case-studies/writer/business-feasibility-financial-models/):** 40+ proposal bisnis teruji perbankan, model arus kas 5 tahun, dan SOP operasional.
- **[Peer-Reviewed Empirical Research (APA 7th)](/case-studies/writer/peer-reviewed-empirical-publishing/):** Naskah jurnal bereputasi (IJMME & AB-JME), Zotero Field Codes asli, dan metodologi PRISMA 2020 SLR.
- **[Cinematic 3D Video & Script (#659866)](/case-studies/writer/cinematic-3d-birthday-video-659866/):** Alur cerita 4 babak 60 detik, sinkronisasi stem audio, dan spesifikasi visual Blender/Unreal.

### [4. Data Analysis](/case-studies/data-analysis/)
Landasan matematika terapan eksak berakar pada pendidikan formal Tadris Matematika (140 SKS, IPK 3.71, Statistika Lanjutan Nilai 89.8 / A-), dipadukan dengan komputasi modern.

- **[Mathematical Modeling & Statistical Computing](/case-studies/data-analysis/mathematical-modeling-and-statistics/):** Rigor matematika, verifikasi asumsi klasik, dan komputasi deterministik (Python/SPSS).
- **[Psychometric & Survey Validation (Rasch & Aiken)](/case-studies/data-analysis/psychometric-survey-validation-rasch/):** Validasi instrumen skala Likert melalui Aiken's V dan Rasch Rating Scale Model.
- **[Resilient CDP WebSocket Scraping Engine](/case-studies/data-analysis/resilient-cdp-websocket-scraping/):** Ekstraksi data stealth via Chrome DevTools Protocol menembus proteksi JavaScript dinamis.
- **[Morpheus V2 Financial Simulation (#659758)](/case-studies/data-analysis/morpheus-v2-tax-simulation-659758/):** Simulasi statutory tax presisi tinggi berbasis modul `Decimal` tanpa kesalahan pembulatan binary float.
- **[DocuMorph PDF & Table Extraction Pipeline](/case-studies/data-analysis/documorph-pdf-table-extraction/):** Transformasi deterministik laporan keuangan PDF menjadi dataset terstruktur CSV/Excel.
