## 1. Executive Summary

Banyak toko WooCommerce mengalami lonjakan bounce rate dan keranjang belanja ditinggalkan (*cart abandonment*) karena lambatnya respon server saat pelanggan melakukan aksi filter produk atau checkout. Masalah ini umumnya bukan disebabkan oleh spesifikasi server, melainkan tumpukan query lambat pada tabel `wp_options` (transient kedaluwarsa) dan `wp_usermeta`, serta konflik plugin yang menghabiskan memory limit PHP.

Cetak biru ini menyajikan metodologi isolasi staging non-destruktif untuk memulihkan kecepatan toko online tanpa risiko kehilangan data pesanan riil pelanggan.

## 3. Diagnostik PHP Mandiri (wc_health_audit.php)

Berikut skrip diagnostik berbobot ringan untuk memetakan kesehatan memori, versi dependensi, dan akumulasi autoload options:

```php
<?php
/**
 * WooCommerce Health & Performance Auditor (Stand-Alone Diagnostics)
 * Non-destructive audit for WooCommerce environments.
 */

define('WP_USE_THEMES', false);
if (file_exists(__DIR__ . '/wp-load.php')) {
    require_once __DIR__ . '/wp-load.php';
}

$audit_results = [
    'timestamp'       => gmdate('Y-m-d\TH:i:s\Z'),
    'php_version'     => phpversion(),
    'memory_limit'    => ini_get('memory_limit'),
    'max_exec_time'   => ini_get('max_execution_time'),
    'active_plugins'  => [],
    'autoload_size_kb'=> 0,
];

if (function_exists('get_plugins')) {
    global $wpdb;
    $autoload_size = $wpdb->get_var("SELECT SUM(LENGTH(option_value)) FROM {$wpdb->options} WHERE autoload = 'yes'");
    $audit_results['autoload_size_kb'] = round($autoload_size / 1024, 2);
    $audit_results['active_plugins']   = get_option('active_plugins', []);
}

header('Content-Type: application/json');
echo json_encode($audit_results, JSON_PRETTY_PRINT);
```
