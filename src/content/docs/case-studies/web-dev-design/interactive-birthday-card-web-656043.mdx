## 💼 2. Business Value: Why 8-Beat Journey Cards Outsell Static E-Cards

Modern consumers do not want static digital greeting cards. Flat JPEG images and pre-rendered MP4 video attachments suffer from immediate attention drop-off: recipients look at them for 4 seconds, tap close, and forget them.

HeartCraft proved that interactive web cards command premium pricing ($5 - $15 per link) because they transform a greeting into an **interactive tactile experience**.

### The 4 Commercial Advantages of the 8-Beat Engine:

1. **Micro-Dopamine Pacing (4x Retention):**  
   Instead of overwhelming the user with a wall of text, the card guides the recipient through 8 bite-sized sensory beats. Each action (popping a balloon, blowing a candle, slicing cake) rewards the user with audio feedback and particle visuals.
2. **One Engine, Infinite Niche Themes (High Margin Agency Model):**  
   All content and colors are decoupled into a single declarative configuration file (`config.js`). A creator or agency can resell this exact engine across dozens of lucrative verticals (Kids Pastel, Midnight Gold Luxury, Bollywood, Retro Pixel, Romantic Anniversary) by changing only 10 lines of JSON.
3. **Frictionless Web Link Delivery (No App Download):**  
   Recipients open the card directly in Safari iOS or Chrome Android from WhatsApp, iMessage, or Instagram DMs. No App Store installs, no accounts, and no barriers.
4. **Zero Ongoing Server Costs:**  
   Pure client-side execution allows the card to be hosted on free edge tiers (GitHub Pages, Cloudflare Pages, Netlify) with sub-second Time to Interactive and zero recurring compute bills.

## 🤖 5. The Two-Track Agentic Workflow (Rive CLI vs Host Web Engine)

To enable autonomous coding agents (Claude Code, Cursor, Antigravity) to maintain and scale templates without breaking runtime behavior, the architecture strictly separates vector state-machine authoring from web narrative orchestration:

```text
┌────────────────────────────────────────────────────────┐
│  Track A: Vector Asset Authoring (Rive CLI + RML)      │
│  - Text-based RML (Rive Markup Language) + Luau        │
│  - Headless QA: rive --verify && rive --screenshot     │
│  - Outputs clean, production-grade .riv binary assets   │
└──────────────────────────┬─────────────────────────────┘
                           │
                 [Frozen State Contracts]
                 ├── Triggers: pop | blow | open | cut
                 ├── Booleans: isLit | isOpen
                 └── Out Events: opened | allOut | sliced
                           │
┌──────────────────────────▼─────────────────────────────┐
│  Track B: Narrative Host Engine (Web DOM + Audio)      │
│  - 8-Beat Scene State Machine in Vite / Astro          │
│  - Web Audio AnalyserNode (blowDetector.js)            │
│  - Lightweight Canvas Confetti & DOM Typewriter Letter │
└────────────────────────────────────────────────────────┘
```

### Frozen Contracts Specification (`contracts.js`)
By freezing interaction tokens, AI agents generate asset variations (e.g., swapping balloons for floating lanterns) without touching or breaking the host web code:

```javascript
export const RIVE_CONTRACTS = {
  inputs: {
    triggers: ['pop', 'blow', 'open', 'cut', 'celebrate'],
    booleans: ['isLit', 'isOpen'],
    numbers: ['cutProgress', 'balloonCount']
  },
  events: ['opened', 'popped', 'allOut', 'sliced', 'done'],
  viewModel: ['recipientName', 'age', 'themeColor']
};
```

## 🛡️ 6. Mobile Ergonomics & Technical Safeguards

* **Viewport Height Stabilization:** Uses modern `100dvh` and `-webkit-fill-available` CSS declarations to eliminate the notorious mobile Safari bottom address bar jumping bug.
* **Audio Autoplay Unlock:** Complies with iOS/Android strict media policies by unlocking the Web Audio API context on the first user pointer-down interaction.
* **Microphone Blow Detection with Tap Fallback:** Uses `getUserMedia` with an RMS volume energy threshold to detect real candle blows, while seamlessly falling back to direct touch for users who decline microphone permissions.
* **Zero Heavy External Dependencies:** The entire engine runs in vanilla JavaScript without GSAP or external MP3s, weighing under 35KB and loading instantly even on spotty 3G mobile networks.
* **Touch-Action Lock:** Prevents accidental page pull-to-refresh and rubber-band bounce, keeping the user immersed in the 8-beat experience.
