The **Web Dev Design** pillar encompasses modern frontend engineering, responsive design systems, and robust web applications engineered for extreme performance, sub-second latency, and serverless edge scalability.

---

## Core Engineering Philosophy

1. **Sub-Second Performance & Green Core Web Vitals:** Every deliverable is optimized for Largest Contentful Paint (LCP) < 1.0s, Cumulative Layout Shift (CLS) 0, and Interaction to Next Paint (INP) < 100ms.
2. **Serverless Edge Architecture:** Leveraging static edge compilation and workers (Cloudflare Pages, Vercel Edge, GitHub Pages) eliminating legacy server maintenance overhead and dynamic SQL injection vectors.
3. **Academic White Institutional Design System:** Curated editorial typography (Newsreader & Inter), clean Slate 50 canvas `#F8FAFC`, institutional navy accents `#1E3A8A`, and verified WCAG 2.1 AA / AAA contrast compliance.
4. **Staging Sandbox Isolation & Zero Downtime:** Every production code change undergoes non-destructive staging verification and deterministic regression testing.
