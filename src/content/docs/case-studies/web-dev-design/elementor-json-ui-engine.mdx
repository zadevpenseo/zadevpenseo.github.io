## 1. The Dilemma: Addon Bloat vs Native JSON

Mayoritas agensi WordPress memasang puluhan plugin tambahan (Essential Addons, Ultimate Addons, dll.) untuk membuat komponen modern, mengakibatkan:
- DOM tree yang sangat dalam (> 32 level).
- Puluhan berkas CSS dan JavaScript yang dimuat secara bersamaan dan memblokir render browser.
- Kerentanan keamanan dan risiko kerusakan antarmuka saat WordPress diperbarui.

Solusi kami adalah merekayasa komponen langsung ke dalam struktur skema **Elementor Native JSON**:
- Menggunakan widget inti WordPress/Elementor murni.
- Menghasilkan berkas template JSON yang dapat diimpor langsung tanpa memerlukan plugin eksternal apa pun.
- Keteraturan CSS menggunakan custom CSS selector scoped (`selector { ... }`).
