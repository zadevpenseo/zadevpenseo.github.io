## 1. The Core Law of Single-Source Academic Typesetting

In academic journal publishing, authors submit raw manuscripts in Microsoft Word format (`.docx`). Modern publishers demand three distinct deliverables for every accepted paper:

1. **JATS XML (Journal Archiving and Interchange Tag Suite):** The non-negotiable standard required by PubMed Central, Crossref, and indexing databases.
2. **Press-Ready PDF:** Millimeter-accurate two-column layouts matching strict journal geometry, font leading, running headers, and vector equation rendering.
3. **Responsive HTML:** Semantic web articles with accessible tables and inter-document citation hyperlinks.

Traditional publishing desks treat these targets as three disconnected conversion tasks. When an author requests a late proof correction, the editor updates the PDF, but the modification quietly fails to reach the archived XML data. This defect, known as **Source Drift**, corrupts indexing metadata and compromises empirical replicability.

Our pipeline resolves this systemic failure by enforcing a **Single Source of Truth (SSOT)**: the Word manuscript is normalized into canonical JATS XML v1.3 first, and all downstream assets (press PDF and responsive HTML) are compiled directly from this validated master.

## 3. High-Performance Compilation via Typst CLI

Unlike legacy LaTeX systems that require heavy distributions (often exceeding 2 GB of disk space and consuming significant memory), our PDF compilation pipeline utilizes **Typst 0.15**:

- **Ultra-Low Memory Footprint:** Consumes less than 30 MB RAM during document generation, operating comfortably within low-power workstations.
- **Sub-Second Compilation Latency:** Generates complete press-ready PDFs in approximately 0.42 seconds, enabling real-time preview during editorial reviews.
- **Vector Typography Integrity:** Embeds scalable Type 1 and TrueType font metrics (Times New Roman, Arial, New Computer Modern Math) with zero rasterization artifacts.
- **Deterministic Pagination:** Enforces strict widow and orphan suppression across balanced two-column body text.

## 4. Automated Preflight Quality Assurance

Every generated publication package clears three deterministic quality gates before client delivery:

1. **JATS Schema Gate (`lxml` / `xmllint`):** Confirms well-formedness, valid root `<article>` hierarchy, complete metadata, and zero unresolved cross-reference citation IDs.
2. **Press PDF Audit (`PyMuPDF`):** Analyzes page dimensions, confirms unencrypted standard delivery, and validates that 100% of body text renders via embedded vector fonts.
3. **HTML Responsive Parity:** Verifies valid stylesheet linkages, horizontal table overflow containment on mobile viewports, and functional intra-document jump anchors.
